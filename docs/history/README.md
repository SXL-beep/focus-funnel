# Project history

This directory is the safe, commit-ready history for Focus Funnel.

- `PROJECT-HANDOFF.md` records the verified migration state, current product
  state, known documentation conflicts, and likely next work.
- Git is the authoritative change log. Run `git log --oneline --decorate` for the
  complete 63-commit development history present at migration.
- Detailed historical conversations live locally under
  `.private/conversations/`. They are excluded from Git because the repository is
  public and historical chats may contain private operational information.

The conversation archive contains redacted, readable exports rather than raw
JSONL. Canonical copies were used where the migration contained repeated snapshots
of the same conversation. Its generated `INDEX.md` records those mappings.
